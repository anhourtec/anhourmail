# @anhourmail/ui

Design system shared by `apps/web` (console + webmail), `apps/site` and `apps/docs`: tokens (`styles/tokens.css`),
type scale (`styles/type.css`, `am-*` classes), self-hosted brand fonts, `cn()` and loading skeletons.
shadcn/ui primitives are generated per app (`components/ui`, not linted) on top of these tokens.
Rules: docs/internal/branding.md and docs/internal/typography.md.

General Sans font files: Fontshare, ITF Free Font License.
