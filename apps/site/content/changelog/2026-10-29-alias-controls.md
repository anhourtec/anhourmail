---
title: Aliases an administrator turns off stay off, and a daily creation limit
date: 2026-10-29
summary: An alias an owner or user administrator turns off can only be turned back on by them; each account can create a set number of aliases per day.
---

- **Turned off by an administrator.** When an owner or someone who manages users turns off an alias of someone
  else's mailbox, the list shows **Turned off by an administrator**. The mailbox's person still sees it but can't
  turn it back on or delete it; an administrator turning it back on gives it back to them. See
  [Aliases](/docs/aliases#turning-aliases-off-and-deleting-them).
- **A daily creation limit.** Each account can create a set number of aliases, and separately of masked aliases, per
  day (midnight to midnight UTC). Deleting one doesn't give it back. If you reach it, the console says so and when you
  can create more. The numbers are in [How many can I have?](/docs/aliases#how-many-can-i-have).
