Using your own domain is part of the paid plans. You keep your domain where it is; you only add a few DNS
records at your DNS provider (often the company you bought the domain from).

## Before you start

- You need to be able to edit DNS records for the domain.
- If mail already arrives somewhere else for this domain, it moves to AnhourMail once the inbound record below
  is in place. Plan the switch for a quiet moment.

**Required** records are needed before the domain works. **Recommended** records make mail apps set themselves
up and help your mail reach inboxes.

## How long does it take?

DNS changes usually show up within minutes, but some providers take a few hours. The console re-checks a new
domain every few minutes for its first week, and you can press **Check now** at any time. Each record shows
**Found**, **Missing**, **Different value** (with what we found instead) or **Couldn't check** (try again shortly).

Once the required records are found, the domain shows **Setting up** for a minute or two, then **Active**.

## Common problems

- **The name already has a value.** Some providers add the domain for you. If the name field shows your domain
  already, enter only the part before it.
- **There is already an SPF record.** A domain can have only one. Merge ours into the existing one instead of
  adding a second.
- **"DKIM not found in DNS — mail will fail DKIM."** Each DKIM record only counts once the signing key it points to
  answers in DNS. Check the name and value of both DKIM records; if the console says your record is right, the key
  behind it isn't published yet and the domain stays pending until it is, so your mail isn't sent unsigned.
- **Verification is still pending after a day.** Make sure there is no typo in the verification code, then press
  **Check now**.

## Removing a domain

Open the domain from the **Domains** list, go to its **Overview** tab and choose **Remove domain…**. Remove or move its mailboxes and aliases first; the console tells
you if any still use it. You can add the domain again later.

## If someone else already added your domain

Adding a domain doesn't claim it: only the account whose verification record is published can make it active. If
the console says the domain is connected to another account and it's yours, contact support.
